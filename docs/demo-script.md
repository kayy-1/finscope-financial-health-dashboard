# 90 秒演示脚本

## 0—15 秒：问题

“这个项目解决的问题是：把连续三年财报从分散的科目，整理成能快速阅读的经营指标、风险线索和情景预测。”

## 15—35 秒：经营概览

打开页面，指出自动摘要、五项核心指标和近三年组合图。

“示例企业收入仍在增长，但净利率和现金转化走弱，资产负债率已经达到 50% 的观察线。”

## 35—55 秒：风险解释

向下指出四条风险线索。

“这里不是给企业贴风险标签，而是把指标变化转换成需要核查的问题。例如现金转化偏低时，需要继续看应收账款、存货和合同负债。”

## 55—75 秒：情景预测

调整收入增速或毛利率滑块。

“收入和毛利率变化会实时传导到 2027 年净利润与敏感性矩阵。模型故意保持简化，避免把不确定假设包装成精确预测。”

## 75—90 秒：工程与交付

展示导出按钮和文档入口。

“财务公式由 Python 单元测试验证，前端无外部依赖并配置了 GitHub Pages；仓库中同时提供 MySQL 表结构、公式说明和 Vibe Coding 过程记录。”

## 简历项目描述

**衡镜：财报健康分析与风险预警｜个人 Vibe Coding 项目**

- 使用 HTML、CSS、JavaScript 与 Python 完成从需求拆解、指标建模、交互预测到部署交付的完整闭环。
- 支持三年财报分析、六类风险规则、情景预测和敏感性矩阵，并用单元测试校验核心公式。
- 提供零登录在线 Demo、CSV 导入、MySQL 表结构、GitHub Pages 工作流和 90 秒演示材料。
