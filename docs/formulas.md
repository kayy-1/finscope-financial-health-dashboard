# 财务指标与计算口径

## 金额单位

所有金额统一使用人民币百万元。示例 CSV 保留整数，内部计算使用浮点数，展示时按指标需要保留一到两位小数。

## 核心指标

| 指标 | 公式 | 解释 |
| --- | --- | --- |
| 营收增速 | `(本期收入 - 上期收入) / 上期收入` | 衡量经营规模变化，不区分量价因素 |
| 毛利率 | `(营业收入 - 营业成本) / 营业收入` | 衡量产品与成本结构带来的初始盈利能力 |
| 净利率 | `净利润 / 营业收入` | 衡量收入最终转化为净利润的比例 |
| 期间费用率 | `期间费用 / 营业收入` | 项目假设期间费用包含销售、管理和研发费用 |
| 资产负债率 | `总负债 / 总资产` | 衡量资产由负债支持的比例 |
| 流动比率 | `流动资产 / 流动负债` | 衡量短期偿债资源的账面覆盖 |
| ROE | `净利润 / 期末权益` | 为保持演示口径简洁，使用期末权益，不采用平均权益 |
| 现金转化 | `经营现金流净额 / 净利润` | 衡量利润的现金含量，净利润为负时不作正面解释 |

## 风险观察线

风险规则用于触发阅读线索，不代表企业已经发生违约或经营失败。

| 规则 | 触发条件 | 等级 |
| --- | --- | --- |
| 收入收缩 | 营收增速小于 0 | 高 |
| 收入放缓 | 营收增速低于 3%，或较上年下降至少 4 个百分点 | 中 |
| 毛利承压 | 毛利率同比下降超过 0.5 个百分点 | 中；超过 2 个百分点为高 |
| 现金含量偏低 | 现金转化低于 0.85x | 中；低于 0.65x 为高 |
| 杠杆空间收窄 | 资产负债率达到 50% | 中；达到 65% 为高 |
| 短期偿债不足 | 流动比率低于 1.0x | 高 |

阈值被固定在代码中，便于演示和测试。真实业务中应按行业基准、企业信用政策和债权人要求分别配置。

## 三年预测

预测采用简化利润表模型：

```text
预测收入 = 上一年收入 × (1 + 年收入增速)
毛利 = 预测收入 × 毛利率
经营利润 = 毛利 - 预测收入 × 期间费用率
税前利润 = 经营利润 - 其他损益
净利润 = 税前利润 × (1 - 所得税率)
```

“其他损益”根据最新一期实际数据反推，使基准年预测净利与历史净利口径保持近似一致。所得税率默认 22%。

该简化模型不覆盖：

- 营运资本变化
- 应收账款和存货导致的现金占用
- 资本开支和折旧摊销
- 有息负债、利息费用和融资活动
- 非经常性损益、少数股东权益和会计政策调整

因此结果用于情景讨论，不作为盈利预测或估值结论。

## 敏感性分析

敏感性矩阵固定期间费用率和税率，以收入增速为列、毛利率为行，计算第三年的预测净利润。高亮单元格表示当前选择的情景。
